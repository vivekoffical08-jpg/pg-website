## 15. Animation & Interaction Rules

- **Design Philosophy:** Restrained, elegant motion that communicates hospitality luxury. Animation must never delay content consumption.
- **Permitted Interactions:**
  - **Header scroll transition:** CSS transition (`0.3s cubic-bezier(0.25, 0.46, 0.45, 0.94)`).
  - **Scroll reveal:** `IntersectionObserver` adding `.revealed` to `.reveal` elements (opacity `0` to `1`, translateY `24px` to `0px`).
  - **Card & Image hover:** Subtle scale (`scale(1.025)` or `scale(1.03)`) with eased transitions.
  - **Button transitions:** Background and text color shifts with `translateY(-2px)` elevation.
  - **Gallery Lightbox:** Smooth fade-in overlay with keyboard navigation (`Escape`, `ArrowLeft`, `ArrowRight`) and touch swipe detection.
- **Strictly Prohibited Animations:**
  - Parallax that causes jank or layout instability.
  - Bouncing, spinning, or flashy bouncing badges.
  - Artificial full-screen loading spinners.
  - Uncontrollable carousel auto-scrolls that disorient users.
- **Accessibility Safeguard (Reduced Motion):**
  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
      scroll-behavior: auto !important;
    }
  }
  ```
